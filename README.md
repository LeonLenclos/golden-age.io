# golden-age.io

Golden Age is a Multiplayer Online Real Time Strategy Game currently in early development.

## Roadmap

### alpha 1

The first version of the game, developed in 2022.

### alpha 2

### beta

The first version to be released online. It needs to be fully playable, user-friendly, and visually appealing.

This requires revising the menus, interface, and graphics, as well as making the final tweaks to the game.

### version 1

The first official version of the game. It differs very little from the beta.

The plan is to fix the bugs discovered during beta testing and to incorporate player feedback on gameplay and accessibility—all without making any major changes.

### version 2

A donation-funded version that requires version 1 to be successful and popular.

This version will include major changes. These changes will be decided later but could include, for example, game modes, leaderboards, skins, and more.
